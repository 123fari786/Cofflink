# Cofflink

**AI-Powered Flutter Mobile Application for Real-Time Communication, Nearby User Discovery, Flight Information, and AI Avatar Generation.**

Cofflink is a Flutter-based mobile application that combines real-time communication, location-based user discovery, flight information, and AI-powered features in a single mobile experience.

The application integrates **Flutter, Firebase, REST APIs, and AI services** to provide users with real-time interactions and intelligent application features.

---

## 🚀 Key Features

* 🔐 **User Authentication**

  * Firebase Authentication
  * Secure user registration and login

* 💬 **Real-Time Chat**

  * Online and offline messaging
  * Real-time communication using Firebase

* 📍 **Nearby User Discovery**

  * Discover users based on location
  * Location-based user interaction

* ✈️ **Flight Information**

  * Real-time flight information
  * Flight data integration through APIs

* 🤖 **AI Avatar Generation**

  * AI-powered avatar generation
  * Personalized user experience

* 🌐 **REST API Integration**

  * Integration with external APIs
  * JSON-based data communication

* 📱 **Responsive Flutter UI**

  * Modern mobile interface
  * Responsive layouts for different screen sizes

## ⚙️ Getting Started

### Prerequisites

Before running the project, make sure you have installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android SDK
* Git

Check your Flutter installation:

```bash
flutter doctor
```

---

## 📥 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/123fari786/Cofflink.git
```

### 2. Open the Project

```bash
cd Cofflink
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run
```
